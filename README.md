# FirstForm – Registracijski obrazec

## Opis projekta
Mobilna aplikacija, izdelana v Android Studiu z uporabo programskega jezika Java. Namen aplikacije je izdelava registracijskega obrazca za vnos osnovnih uporabniških podatkov.

## Funkcionalnosti
- Vnos uporabniškega imena (Username).
- Vnos polnega imena (Full name).
- Vnos države (Country).
- Vnos e-poštnega naslova (Email).
- Vnos telefonske številke (Phone number).
- Vnos gesla (Password).
- Izbira spola (Male / Female).
- Potrditev pogojev uporabe (Terms & Conditions).
- Prikaz povzetka vnesenih podatkov v pogovornem oknu (Registration Details).
- Uporaba ScrollView za dostopnost obrazca na manjših zaslonih.

## Uporabljene tehnologije
- Android Studio
- Java
- XML
- Android SDK
- AlertDialog.Builder

## Zagon aplikacije
1. Projekt odpremo v Android Studiu.
2. Zaženemo emulator ali povežemo Android napravo.
3. Kliknemo gumb Run.
4. Izpolnimo registracijski obrazec.
5. Kliknemo Create account.
6. Prikaže se pogovorno okno s povzetkom vnesenih podatkov.
